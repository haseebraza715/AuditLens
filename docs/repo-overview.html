AuditLens

A layered tabular bias-audit library with deterministic statistics, optional task-aware LLM interpretation, and shareable report artifacts.

Evidence-backedLocal-first HTMLSource inspected

The problem it solves

Teams need repeatable dataset fairness checks and context-aware explanations without forcing every notebook user into a hosted UI or an LLM dependency.

Current features

  • Notebook-first audit() API and AuditLensReport HTML/repr/dict helpers
  • Layer 1 class distribution, missingness, sensitive correlation, subgroup parity, severity ordering
  • Layer 2 parse/analyze/clarify/interpret/recommend/report graph with provider fallbacks
  • Markdown/PDF reports and fairness charts
  • Artifact storage and process-local async report jobs
  • FastAPI upload/analyze/task/report endpoints
  • Streamlit configuration, clarification, risk, chart, and download workflow
  • Synthetic quickstart with versioned expected result

Main execution flow

  1. Accept a DataFrame or uploaded CSV and validate target/sensitive columns.
  2. Run deterministic analyzers for distribution, missingness, correlations, and subgroup parity; sort issues by severity.
  3. Return Layer 1 directly when no task description is supplied.
  4. Otherwise build task context, ask clarifying questions if ambiguous, then interpret issues and generate mitigations through the optional LLM graph.
  5. Render Markdown/PDF and optionally persist metadata/content for synchronous download or process-local job polling.

Installation and run commands

Commands below are taken from the repository. Run them from the project root unless the first command changes directory.

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
python3 -m pip install -e ".[dev]"
python3 -m pytest tests/
python3 -m pip install -e ".[server]"
python3 -m uvicorn auditlens_server.app:app --reload --env-file .env
python3 -m streamlit run ui/auditlens_ui/app.py
Local verification. Ran python3 -m pytest -q tests -m 'not slow and not e2e': the fast suite passed; only deprecation/OpenSSL warnings were emitted.

Implemented, partial, and planned

implemented

All three layers, public library API, optional provider graph, Markdown/PDF/charts, artifacts/jobs, FastAPI server, Streamlit UI, and tests.

partial

Background jobs live only in one process and disappear on restart; server upload limits default to 10 MiB and 100,000 rows.

planned

PyPI Trusted Publishing workflow exists, but README phrases installation as available only after the first release is uploaded. Historical roadmap items are not current claims.

Known limitations and technical debt

  • Users must identify target and sensitive columns; automated proxy/sensitive attribute detection is not part of the current public API.
  • Async jobs are in-memory, non-durable, and incompatible with multiple Uvicorn workers.
  • Layer 2 depends on provider credentials and can inherit model ambiguity/nondeterminism.
  • PDF/charts/server/UI are optional extras rather than core installation behavior.
  • Historical docs under docs/internal and the next-phase roadmap can conflict with current shipped status if read without their warnings.
